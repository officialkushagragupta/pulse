# Pulse

Pulse is an internal agentic "digital employee" for the fictional AcmeTech enterprise — it executes tools (it is not a chatbot) across four domains: HR, IT, Engineering, and Analytics. The repo is a monorepo of six **independently deployable microservices** (`mcp-client`, `mcp-wrapper`, `tools-service`, `gmail-mcp-server`, `outlook-mcp-server`, `knowledge-base-mcp-server`) with no shared root dependency surface — each owns its own `pyproject.toml`, `.env`, and `Dockerfile`, and follows a hexagonal layout (`src/{domain,application,infrastructure,api}`) where `domain/` depends on nothing and `api/dependencies.py` is the composition root. Services communicate only over MCP/HTTP at runtime (client → `mcp-wrapper` discovery/routing gateway → owning server → tool); resources are owned, not shared (Postgres belongs to `tools-service`, the FAISS/BM25 index to `knowledge-base-mcp-server`).
